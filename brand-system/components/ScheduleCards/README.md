Schedule information always uses the same three pieces.

- **Training card:** `charcoal`, `r-module` corners, yellow labels (Days, Time, Where) over white Anton values. Training is weekly, so it lives in this card and never in the event list.
- **Next game card:** white with a 2px `charcoal` border, maroon labels, "LIONS VS [OPPONENT]" in Anton. When there's no game, show "Off-season" with one line about when the season runs (April to mid-October).
- **Schedule row:** a charcoal date block (yellow month, white Anton day), a type tag (Game: `maroon-600` with white text; Social: `yellow-500` with charcoal text) that always includes the word, then the title, time and venue.

Provide: real dates, times, opponents and venues from the club. Placeholders in square brackets are for templates only and never go live.
