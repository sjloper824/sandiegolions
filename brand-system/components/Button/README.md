Buttons are squared (`r-btn`, 2px), uppercase Work Sans 800 at 14px with 0.05em tracking and 15×28px padding.

- **Primary:** `yellow-500` fill, `charcoal` text. Use one per section, for the main action (Join the Lions, RSVP, Full calendar).
- **Maroon:** `maroon-600` fill, white text. Used only for the header Join button and the phone menu.
- **Ghost:** 2px `maroon-600` border and text on white. On maroon or charcoal panels, use a white border at 70% and white text.
- **Text link:** `maroon-600` uppercase text with a 3px `yellow-500` underline, for a secondary "see more" action.

Provide: the label (2–4 words, a verb first) and a real link. On phones, buttons in a call-to-action row go full width. Never round a button, and never put two yellow buttons side by side.
