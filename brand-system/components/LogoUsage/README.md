Three approved marks, always the real artwork from Assets › Logos.

- **Lion lockup** (`clean-logo.png`): the everyday logo for the website, social, email and flyers. On maroon or charcoal, knock it out to all white (on the web: `filter: brightness(0) invert(1)`).
- **Crest** (`crest-logo.png`): formal uses only (anniversaries, awards, life members, the sponsor deck cover, the tent back wall). Keep it on white; it carries its own navy and maroon.
- **Script wordmark** (`script-wordmark.png`): social events and merch. Never the main logo.

Clear space is a quarter of the logo's height. Minimum height is 32px on screen and 0.6 in in print (crest: 72px or 1 in). Never recolour except the all-white knockout, never stretch, rotate, outline or redraw, and never place on a busy photo. Order vector files before any large-format print.
